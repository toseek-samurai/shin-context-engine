# Reporting a vulnerability

Send suspected security vulnerabilities privately to **toseek@gmail.com**.
Do not disclose them in public issues or include credentials, private source
code, or personal data in the initial report.

Include the affected version or source revision, platform, a minimal synthetic
reproduction, expected behavior, and observed impact. Redact private paths and
tokens from diagnostic output. If sensitive material is needed, agree on a
transfer method before sending it.

The public source is currently a development candidate. No support window or
response-time guarantee has been established. Acknowledgement and remediation
will be coordinated with the reporter before public disclosure where practical.
