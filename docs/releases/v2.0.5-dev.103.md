# v2.0.5-dev.103

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Retry transient Windows CMake download failures and fall back to the official CMake server. The pinned version and SHA-256 remain unchanged; extraction starts only after verification.
- Fetch pinned macOS qualification archives through the GitHub API when the public release download route fails. Both previous-generator and previous-release checks retain the exact tag, asset name, byte count and SHA-256.
- Retry curl transport failures within bounded limits and discard partial downloads. Checksum or size mismatches fail qualification without switching sources.
- Add regression coverage for direct downloads, API fallback, partial files, malformed identities, checksum failures and failed recovery downloads.
- Retain the kit recovery, rollback and compiler-cache improvements from dev.101/dev.102. Platform packages publish only after their own source and exact-archive qualification succeeds.

Core is `2.0.5-dev.20`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.103`.
