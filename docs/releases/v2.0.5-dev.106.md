# v2.0.5-dev.106

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Recognize successful saved update attempts that have been superseded by a newer independently verified installation. Require a different manifest, strictly newer versions, no active updater writer and no pending native recovery. Preserve the historical result without blocking the next release offer.
- Make the verified outcome take precedence over the saved phase in Monitor and TUI. A raw installed phase can no longer hide the acknowledgement action when review is required.
- Show superseded attempts as older results and keep new offers available in both interfaces. Active operations, unknown outcomes and current native recovery remain blocking.
- Add regression tests for superseded attempts, unchanged or older installations, invalid versions, active writers, native recovery and the EN/RU update windows.

Core remains `2.0.5-dev.22`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.106`.
