pass qualification in CI.

  only to the verified installer while retaining its immutable file/parent pins.
  Restore its private permissions after the Installer process; other staged
  files, project data, settings and approvals keep their existing permissions.

  only when the original installed version and complete inventory still verify.
  Other unknown Installer outcomes continue to block another installation.

  three-worker limit and outer 45-second CTest deadline. Schedule independent
  source-race and returned-observation families separately; retain the combined
  diagnostic selector and all safety/recovery assertions.

  Require the authoritative source profile as an agent entry point; generated
  locators still require their exact external output and cannot use source-local
  decoys. Preserve source, ranking, evaluation and resource bounds.
- Add native MSI permission/recovery regressions and portable scheduler/profile
  ownership tests. No test deadlines or safety checks are relaxed.
- Keep budgeted agent entrypoints in LF on Windows and POSIX. Account for the
  source-discovery suite's internal readers in CTest's existing four-slot
  workload; retain its 60-second deadline and the suite's concurrency checks.
