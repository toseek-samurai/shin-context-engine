# v2.0.5-dev.109

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Let running MCP connections discover newly allowed projects from their selected agent settings without restarting the agent. Codex, OpenCode, Command Code and Hermes retain independent explicit project lists; service enrollment grants no additional MCP access.
- Show configured, unconfigured, review-required and one-time reconnect states per agent/profile in macOS and Windows Monitor, with EN/RU captions. These states describe configuration, not verified model use.
- Preserve existing settings, comments, other servers and private backups through the reviewed connection workflow. Recheck trusted settings ownership, permissions, links and identity on live reads; invalid settings refuse access.
- Retain continuing project selectors across unrelated additions. Revoke removed or disabled grants and withhold in-flight source results after revocation; re-granted roots receive fresh selectors.
- Extend regression coverage across all four configuration formats, persistent MCP processes, neighboring agents, revocation during retrieval, settings tampering and bilingual native connection windows.

Existing static connections need one host MCP reload/reconnect to adopt the live
catalog. Later project additions need no restart. Initial host activation remains
host-owned; manual configuration exports retain explicit startup-only roots.
The adapter contract fingerprint changes for this cutover.

Core remains `2.0.5-dev.22`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.109`.
