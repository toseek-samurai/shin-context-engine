# v2.0.5-dev.111

Each platform is published after its source and exact package pass qualification
in CI.

- On Windows, Monitor saves the window placement when handing off to the updater.
  It reports the verified MSI installation and project preparation separately.
  If a project needs attention after installation, retry preparation from Monitor
  using the installed kit. Monitor can offer newer releases once preparation ends.
- On macOS, update review and recovery use one verified installation receipt for
  both the outcome and its review revision. A changed receipt requires a fresh
  review before continuing.
- Both desktop Monitors review all selected agent connections before writing
  settings. A conflict during apply reports where it stopped and which agents
  were already connected.
- Monitor and the terminal use the same service diagnostics for project status.
  Temporary refresh or project activity gives the user a status to follow and
  keeps durable project problems visible.
- Core reports the same retrieval mode across briefs, packs, diagnostics and
  evaluation. The index format stays at `shin-generator-v24-objective-cpp`.
- Release preparation checks that CI job, step and artifact names match the
  guarded publisher's requirements before creating a preview tag.

Core is `2.0.5-dev.22`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.111`.
