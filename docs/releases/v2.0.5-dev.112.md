# v2.0.5-dev.112

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Reduce macOS idle-checkpoint descriptor use by coalescing FSEvents roots while retaining source, output and authority verification.
- Record qualification cache, snapshot, generation, profile, doctor, adoption, fingerprint and full-readiness stages in bounded progress and retained diagnostics, including worker timeouts.
- Distinguish a qualified project whose reader is warming from a project awaiting qualification. Pending MCP status explicitly permits one useful query with automatic bounded waiting.
- Update client guidance and add regression coverage for descriptor pressure, unrelated filesystem events, root replacement, timeout diagnostics and reader eviction/recovery.

The 60-second stage stall and 180-second operation bounds remain enforced. Project approvals, source freshness and integrity gates remain mandatory.

Core is `2.0.5-dev.22`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.112`.
