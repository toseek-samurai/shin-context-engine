# v2.0.5-dev.114

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Keep search diagnosis and engine regressions with Shin. Consumer profiles describe source ownership and product scenarios; ordinary document edits do not require rewriting documentation or tuning search counters.
- Check the fragments actually delivered by Eval and Pack-eval with optional `mustEvidence` and `mustNotEvidence` predicates. A matching file alone cannot satisfy a required statement; hidden search text cannot satisfy a displayed-evidence assertion.
- Recognize declared Markdown amendments and replacements, including wrapped ADR preambles. Preserve operative context for partial amendments, qualify superseded sections, and verify the source declarations used to determine their status.
- Preserve complementary owners in small fallback results. Record cumulative retrieval-stage work in full diagnostics and bound optional expansion without adding internal search counters to compact context.
- Return a compact context summary with availability, evidence coverage, next action and scoped retrieval/verification metrics. Search-quality warnings remain visible while safe context stays available; source authority, forbidden-path and safety checks remain mandatory.
- Allow MCP inspect/read to reuse the snapshot from a successful query in the same connection, project and session. Keep explicit snapshots authoritative, expire bounded in-memory bindings, and refuse automatic reuse after failed or overlapping queries.

## Validation

The macOS native source suite covers 169 tests, including 19 new context-outcome
scenarios and MCP session-binding checks. Platform packages still require their
own CI source and exact-archive qualification before publication.

Core is `2.0.5-dev.23`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.114`.
