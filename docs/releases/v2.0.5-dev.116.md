# v2.0.5-dev.116

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Qualify combined document candidates before scoring short-query fallback rows. Successful plans avoid a repeated scoring pass while retaining final coverage, provenance, evidence families, fallback and cumulative work budgets. Resource advisories remain visible; no consumer profile limits or quality expectations are relaxed.
- Move the local service coordinator to pinned, statically linked libuv 1.53.0. Native file notifications, RPC and worker IO, cancellation and one-shot deadlines wake the controller. Preserve FIFO admission, query and refresh deadlines, coalescing, periodic reconciliation and source/authority checks.
- Share macOS FSEvents streams between monitors with identical normalized roots, keeping independent predicates, invalidation tokens, sticky health and teardown fences. Keep explicit refusal and recovery under descriptor pressure.
- Defer child RSS collection until the existing telemetry sample interval is due. Replace storage maintenance's repeated short sleeps with its existing five-minute interval and stop-token cancellation.
- Ship libuv's license and supplemental notices without its development SDK or a separate shared runtime. Keep Homebrew resource staging aligned with the source dependency pins.
- Automate the companion Homebrew tap: select published macOS-qualified source, derive checksums and dependency resources, and advance its formula only after Apple Silicon and Intel installation checks pass.

Local verification covered the complete 171-test macOS suite, nine targeted Linux
tests and eight native Windows tests, including the Windows product MCP path.
Hosted source and exact-package qualification remain mandatory for publication.

Core is `2.0.5-dev.25`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.116`.
