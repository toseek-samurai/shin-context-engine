# v2.0.5-dev.117

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Update the vendored, statically compiled simdjson from 4.6.10 to 5.2.0 for generated JSONL decoding and JUnit UTF-8 validation. Keep the DOM interface, C++20 toolchain, nlohmann control-plane parsing and existing validation rules.
- Add a portable Core regression test for UTF-8 and escaped Unicode, malformed JSON, required provenance, source bounds, recovery after refusal and alternating oversized and small rows. Include it in the Windows Core CI build and smoke preset.
- Synchronize dependency provenance and release checks. Label the earlier decoder benchmark as simdjson 4.6.10 evidence; those historical numbers do not qualify the new version.

Dependency-update validation covered 172 macOS tests, 154 Linux/WSL2 tests and
native Windows Core and desktop sets of 8 and 36 tests. Focused reruns resolved
a macOS GUI focus/frame failure and Linux test-file permission refusals under
`umask 0002`; the latter passed with CI ownership permissions and unchanged
binary bytes. Runtime integrity checks remain strict. Hosted source and
exact-package qualification remain mandatory for publication.

Core is `2.0.5-dev.26`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.117`.
