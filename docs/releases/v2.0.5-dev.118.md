# v2.0.5-dev.118

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Update the vendored Tree-sitter runtime from 0.27.0 to 0.27.2 while retaining the grammar ABI and existing syntax-observation bounds.
- Use checksum-pinned, statically linked SQLite 3.54.1 with FTS5 and thread safety on macOS, Linux and Windows. Native source-cache, history and telemetry no longer depend on a system SQLite version.
- Update Abseil to 20260817.0 and the optional standalone Linux Core CLI allocator to mimalloc 3.6.1. The system allocator remains the default; Observer and Monitor do not acquire an allocator override.
- Remove the retired Server HTTP transport and cpp-httplib, including Observer `deliver`, `reconcile` and `--delivery-config`, their configuration, obsolete contracts and fixtures. Keep local observation, bounded outbox capture, private archive export/verification and strict validation of persisted metadata.
- Extract updated dependency archives with fresh timestamps so an incremental build cannot silently retain objects from an older source archive. Preserve the existing protocol-only MCP SDK pin and adapter contract for persistent clients.
- Align the affected profiles, dependency inventory, build prerequisites and native-package notice checks with the current local-only application.

Versioned macOS source validation passed all 172 CTest cases, including native
installation, MCP update bridging and EN/RU update windows. Dependency-source
probes also passed 154 Linux/WSL2 tests and native Windows sets of 8 Core and
36 desktop tests. The optional Linux allocator passed its scope/ownership checks
and a bounded synthetic index/query probe. Hosted source and exact-package
qualification remain mandatory for publication.

Core is `2.0.5-dev.27`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.118`.
