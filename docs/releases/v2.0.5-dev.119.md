# v2.0.5-dev.119

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Consolidate release-contract text checks to reduce process launches on shared
  CI runners. Preserve the complete regression matrix, canonical version checks
  and the existing 120-second test limit.
- Sign each platform's canonical qualification receipt with GitHub artifact
  attestation after its exact-package checks. Verify the repository, workflow,
  tag, source commit, original run and attempt, and package hashes before
  publication.
- Verify complete published platforms from their signed receipts and release
  downloads, so deleting or expiring temporary Actions artifacts does not block
  a later platform or an idempotent retry. Fresh and interrupted uploads still
  require their exact qualified Actions artifact. Preserve immutable assets and
  refuse missing signatures, source failures and altered package bytes.
- Document the signed publication procedure and cover retry, expiry, interrupted
  upload and coordinated payload/receipt tampering with synthetic tests. Keep
  the existing platform receipt format and Monitor update protocol.

Core is `2.0.5-dev.27`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.119`.
