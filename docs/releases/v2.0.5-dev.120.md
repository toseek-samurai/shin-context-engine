- Include CSS/SCSS, HTML/HTM and Razor/CSHTML in the applicable bundled bootstrap
  profiles. Web-only repositories are recognized without adding documentation.
  Existing native source search returns bounded text with exact source locators;
  CSS cascade, template rendering and framework symbol resolution are not implied.
- Extend the reviewed Russian software vocabulary with general interface terms
  for focus, outlines, selectors, styles, markup and templates. Preserve literal
  identifiers, query budgets and the offline lexical retrieval path.
- Return bounded `source_scope` metadata to agents: selected roots/extensions,
  existing file limits and omitted-entry counts. Scope is informational and
  independent of readiness; files outside it still need direct reads.
- Exercise styles and templates through source discovery, native project setup,
  query delivery and MCP, with EN/RU queries, byte/line verification, dependency
  exclusions, secret quarantine and freshness refusals. Keep permanent project
  profiles, their approvals and search checks unchanged.
