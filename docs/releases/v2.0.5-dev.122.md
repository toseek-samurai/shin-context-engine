# v2.0.5-dev.122

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Save and resume session checkpoints through independent bounded workers after
  project qualification. A cold or busy source reader no longer prevents these
  operations. Preserve authority, current-source and snapshot checks, execution
  limits and per-project ordering; uncertain outcomes require inspecting saved
  state before replacing a checkpoint.
- Make reader preparation easier to diagnose with bounded stage timings and
  clearer on-demand readiness guidance. Count nonwaiting status probes during
  preparation as pending separately from actual admission refusals and errors.
- Ship a selected, byte-checked Codex instruction bundle. CLI and macOS/Windows
  Monitor can review, install, update or recover it through an explicit revision
  confirmation. Preserve user edits, unmanaged files, MCP settings and project
  enrollment; instruction ownership is verified by content receipts.
- Reduce repeated qualification work and reader setup allocations. Share verified
  observations and content checks only within their existing source, publication
  and authority fences; reference source bindings from their immutable snapshot.
- Keep compound-query document coverage planning available when ordinary results
  already fill the output budget. Changing the output limit alone no longer
  disables that route. Ranking, per-document limits and evidence checks remain
  enforced.
- Speed up complete ASCII word matching without changing Unicode, identifier or
  prefix semantics. Reuse parsed lexical metadata and document ownership within
  one retrieval operation only after rereading and comparing the complete input
  bytes. Changed inputs pass the ordinary parser and validation again; retained
  parsing state is bounded and synchronized for concurrent retrieval tasks.
- Refresh installation and platform guides to the qualified dev.121 download
  baseline, and document reader warm-up, checkpoint recovery, telemetry and
  instruction updates.

## Qualification scope

Local source checks passed on macOS (173 tests), Linux (155 tests) and native
Windows (44 Observer/Monitor tests and 11 Core tests). Paired local retrieval
measurements preserved complete responses for the tested workload. These checks
do not qualify release archives or establish a general latency or memory claim.
Release CI qualifies each platform's exact packages independently.

Project sources, profiles, approvals, settings and history remain owned by their
existing authorities. New kits rebuild their derived indexes under current rules.
Generated-format compatibility is unchanged; no historical index reader is added.

Core is `2.0.5-dev.29`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.122`.
