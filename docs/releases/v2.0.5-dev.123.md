# v2.0.5-dev.123

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Set explicit user ownership on the complete parent-directory chain when the
  Windows Codex instruction test seeds an existing skill. The fixture no longer
  depends on the elevated runner's default object owner. Existing-copy adoption
  and customized-copy review keep their original assertions; runtime ownership,
  ACL and link checks are unchanged.
- Retain the independent checkpoint/resume workers, reader diagnostics, reviewed
  Codex instruction updates and retrieval improvements from
  [dev.122](v2.0.5-dev.122.md).

## Qualification scope

All 13 instruction-ownership scenarios passed on native Windows using a standard
user token. The elevated hosted-runner check remains part of release CI, together
with source tests and qualification of each platform's exact packages.

Core remains `2.0.5-dev.29`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.123`.
