# v2.0.5-dev.124

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Preserve the original project refusal when an updated service reports an
  enrollment error in its initial status acknowledgement. Bounded activation
  diagnostics retain causes such as `refresh-engine-changed` while the existing
  authority checks, rollback rules and recovery journal remain enforced.
- Make the update regression exercise early enrollment explicitly. Require the
  original cause in the activation gate itself, so later rollback diagnostics
  cannot mask its loss, and verify that raw project roots remain redacted.
- Retain the Windows instruction-fixture correction from
  [dev.123](v2.0.5-dev.123.md) and the session, readiness, Codex instruction and
  retrieval improvements from [dev.122](v2.0.5-dev.122.md).

## Qualification scope

The strengthened reproduction fails against the published dev.122 macOS kit.
All 173 registered macOS source tests pass with this fix, including native update,
rollback, lifecycle and EN/RU tray checks. Timeouts and safety limits are unchanged.
Source checks do not qualify release archives; CI qualifies each platform's exact
packages independently.

Core remains `2.0.5-dev.29`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.124`.
