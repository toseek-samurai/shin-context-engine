# v2.0.5-dev.125

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

## Changes

- Make compound document planning independent of adjacent output limits. Compare
  missing-owner coverage with the strongest individual match and avoid planning
  owners already represented by ordinary candidates. Synthetic regressions retain
  broad queries, negative assertions and deterministic serial/parallel Pack checks.
- Reuse lexical preparation across scope, scoring and topical checks within one
  immutable row. Masked ownership tokens use fresh fields, preserving scores,
  provenance, evidence and resource accounting without a persistent query cache.
- Exclude local `.dotnet` SDKs and `.playwright-mcp` capture directories from
  source discovery and source-fact collection. Application sources still pass the
  existing scope, freshness, safety and resource checks.
- Align MCP initialization and query guidance with retrieval availability,
  bootstrap readiness and bounded reader warmup. Project-owned profiles follow
  actual owner/root/contract changes; engine misses and resource-counter warnings
  remain Shin's responsibility. Preserve native review, owner authorization and
  strict quality assertions.
- Refresh the installation, client setup and architecture guides against the
  published baseline. Download examples remain pinned to the qualified dev.124
  assets until the next platform packages are published.

## Qualification scope

Resource thresholds and strict quality checks are unchanged. Reducing repeated
work does not imply that advisory resource warnings have cleared. Exact release
archives are qualified independently by CI; local checks do not publish binaries.

Core is `2.0.5-dev.30`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.125`. The generator remains `shin-generator-v24-objective-cpp`.
