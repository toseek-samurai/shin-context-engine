# v2.0.5-dev.126

Compact Brief, Eval and Pack now agree about which text an agent receives.
A strict Pack credits a query group only when the delivered record supports it.
Shared excerpts preserve evidence already visible to earlier requirements.

- Compact excerpts retain matching text inside long paths and identifiers.
  Required and forbidden evidence checks inspect the same fragments as Compact Brief.
- Compact Pack uses unindented JSON. The CLI, Pack evaluation and benchmark
  measure the same representation against existing byte budgets.
- Retrieval reuses scores within a single query and skips full section scoring
  when complete postings and rank bounds establish that a section cannot improve
  the answer. Exact paths and aliases outside the posting vocabulary retain full
  scoring. Wide CLI queries preserve groups beyond the first 64.
- The planner can return complementary rules spread across Markdown sections.
  Scoring diagnostics include work performed inside document and directory scopes.

Core is `2.0.5-dev.31`. Observer and the local kit are `2.0.5-dev.126`.
Each platform publishes its downloads after CI qualifies its exact package.
