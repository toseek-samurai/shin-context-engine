# v2.0.5-dev.127

- Connect a folder and choose its agents. Shin discovers eligible text
  automatically, including unfamiliar file extensions and wikis with `Home.md`.
- Use project `.gitignore` files for the default search scope. A root
  `.shinignore` can exclude additional paths or re-include eligible files with
  `!`. A change to the rules invalidates affected snapshots.
- Updating rebuilds managed indexes directly from the registered folders. The
  automatic route uses the kit's discovery policy and keeps existing agent
  access, settings, and history.
- Large projects use file-level search to narrow the set of files that need
  detailed extraction. Coverage diagnostics report exclusions and omissions.

Core is `2.0.5-dev.32`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.127`.
