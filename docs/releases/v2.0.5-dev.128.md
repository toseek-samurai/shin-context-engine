# v2.0.5-dev.128

The Shin MCP adapter lets clients that probe `server/discover` fall back to
`initialize` over stdio. The handshake negotiates the supported protocol
version with the client. This fixes tool discovery in Codex Desktop after a
reconnect.

Core is `2.0.5-dev.32`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.128`.
