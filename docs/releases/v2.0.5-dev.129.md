# v2.0.5-dev.129

- Managed Markdown resolves relative links from the containing document.
  Bare README references in JSON catalogs can resolve to a sibling file.
  This fixes spurious documentation warnings in projects with nested packages.
- Monitor and TUI keep showing quarantined files when the search reader is on
  demand. The count follows the qualified index and stays visible when some path
  details exceed the status response budget.

Core is `2.0.5-dev.33`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.129`.
