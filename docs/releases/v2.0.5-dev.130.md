# v2.0.5-dev.130

- Managed JSON catalogs preserve package-qualified paths to machine contracts
  and honor explicit document-relative paths.
- Secret scanning treats an empty dotenv assignment followed by a new field as
  two separate assignments. Each field and provider signature is still checked,
  so a non-secret identifier beside an empty credential field stays searchable.

Core is `2.0.5-dev.34`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.130`.
