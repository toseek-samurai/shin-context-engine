# v2.0.5-dev.133

- Indexing and validation share whole-file and physical-line secret detection.
  Shin hides the affected lines before indexing and keeps verified context
  available when a match appears only in an isolated line.
- MCP source fragments identify each hidden range and the rules that triggered
  there. Copied values identify the rules that flagged them elsewhere in the
  same file. Direct source reads include this information in
  `redacted_line_ranges`.
- The kit rebuilds managed indexes with the new source-redaction generator.

Core is `2.0.5-dev.36`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.133`.
