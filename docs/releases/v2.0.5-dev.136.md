# v2.0.5-dev.136

- Monitor brings Overview and Projects to the top of the Sand panel. The footer
  opens Journal, Settings and About Shin. A dedicated dot marks available updates.
- Project pages show search timing, retained activity and agent access. Project
  settings group agent connections, indexing exclusions and disconnection. A
  completed disconnection stays associated with the project that started it.
- Journal entries stay tied to the recorded call when newer events reorder the
  list. Back returns to the journal safely.
- Monitor and TUI share retained chart calculations. RAM includes service and
  worker processes. Hourly samples remain separate points, and missing samples
  or a service restart break a minute-scale line.
- `shin-ce stats` marks search and documentation warnings beside the affected
  project in compact and monochrome views. Project details explain each warning.

Core is `2.0.5-dev.37`. Observer, CLI, MCP, Monitor and Updater are `2.0.5-dev.136`.
