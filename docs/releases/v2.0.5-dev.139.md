# v2.0.5-dev.139

- Keep qualified, unchanged projects current with a compact metadata check. The
  refresh worker budgets retained checkpoints by bytes and favors those that
  save more verification work. Filesystem changes, lost events, and mismatches
  trigger full qualification.
- Share verified source reads for fingerprinting and secret scanning during
  cold reader preparation. The reader takes ownership of the parsed manifest.
- Document formula-specific trust for Homebrew installs.
