This preview shows the installed kit version in Monitor and gates release publication on CI.

- The current version stays visible beneath the panel title in EN/RU and compact layouts, including when the service is disconnected or another update is offered.
- A pushed preview tag runs all four Linux/macOS Core and Observer qualification jobs. Only after they succeed does the publication job download and publish that run's exact macOS archive, checksum and installer.
- Pending, failed, skipped, mismatched or superseded qualification refuses publication. Existing release assets are never replaced with different bytes.
- Native update activation diagnostics and rollback readiness improvements from dev.20 are included. Runtime restoration and pending project readiness remain separate; hard identity, registry and engine refusals retain the recovery journal.

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core remains 2.0.5-dev.3; Observer/CLI/MCP are 2.0.5-dev.21 and Monitor is build 45.

Install or update through Monitor after reviewing the offered release, or run:

```sh
curl -fsSL https://github.com/toseek-samurai/shin-context-engine/releases/download/v2.0.5-dev.21/install.sh | sh
```

Reconnect persistent MCP clients after updating. Project authority, client settings and history stay in their existing data home. Synthetic rollback fixtures do not establish the initiating cause of every historical live failure.
