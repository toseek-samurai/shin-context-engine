This preview adds a visible progress window for updates started from Shin Monitor.

- A separate native window stays open while Monitor closes and the complete kit is replaced. It follows Monitor's selected EN/RU language.
- Downloads show actual received bytes and a percentage. Verification, unpacking, kit checks, installation/restart and final confirmation show named stages with an indeterminate indicator.
- Progress observation cannot block, cancel, retry or certify installation. Existing release approval, checksum, installation ownership, preservation and rollback checks remain authoritative. Monitor reopens to show the saved native outcome.
- Terminal updates retain their JSON output without opening a window.

The progress window is supplied by the installed helper. Updating from dev.25 or an earlier kit to dev.26 still uses the older updater; the window becomes available for subsequent updates launched from dev.26. See [#21](https://github.com/toseek-samurai/shin-context-engine/issues/21).

Native EN/RU window and private transport tests cover real download progress, indeterminate stages, fragmented input, invalid frames and safe completion. Disposable-kit installation/update/rollback tests and Monitor localization/layout checks preserve the existing update behavior.

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core remains 2.0.5-dev.3; Observer/CLI/MCP are 2.0.5-dev.26 and Monitor is build 50.

Choose **Check for updates** in Monitor and confirm that the offered version is **2.0.5-dev.26** before installing. Alternatively:

```sh
curl -fsSL https://github.com/toseek-samurai/shin-context-engine/releases/download/v2.0.5-dev.26/install.sh | sh
```

Reconnect persistent MCP clients after updating. Project authority, client settings and history stay in their existing data home. This release is published only after its matching CI matrix and exact macOS artifact qualification pass.
