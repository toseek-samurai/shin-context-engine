This preview brings the Sand design to native Shin Monitor.

- Warm graphite surfaces, restrained sand accents and the original Shin mark give the panel a consistent appearance. The header displays the installed kit version and provides an EN/RU language menu.
- Project rows show readable states alongside memory and retained request counts. The standard panel is 448×620; compact layouts remain available down to 280×240.
- The memory line chart keeps its light area fill, measurement gaps and service-run boundaries. Hovering retained history shows an observed interval value or an explicit missing measurement.
- Navigation transitions take 160 ms and row highlights take 120 ms. The preparation indicator moves only while work is pending. System reduced-motion settings are respected; rendering stays paused while the panel is closed.
- Diagnostics, profile review, request timing, storage and update controls retain their existing workflows. README screenshots come from native ImGui/Metal fixture renders with synthetic data.

Local verification passed 10 focused checks, including 410 EN/RU ImGui/Metal renders across five panel sizes. The matching CI matrix and exact macOS archive must also pass before this preview is published. See [#23](https://github.com/toseek-samurai/shin-context-engine/issues/23).

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core remains 2.0.5-dev.3; Observer/CLI/MCP are 2.0.5-dev.29 and Monitor is build 53. Native Windows execution is not part of this preview's qualification.

In Monitor, choose **Check for updates** and confirm that the offered version is **2.0.5-dev.29**. After installation, reopen Monitor to see Sand. If an earlier update rolled back, review **Last update result…** and acknowledge its verified outcome before retrying.

Alternatively, install the complete preview with:

```sh
curl -fsSL https://github.com/toseek-samurai/shin-context-engine/releases/download/v2.0.5-dev.29/install.sh | sh
```

Reconnect persistent MCP clients after updating. Existing project authority, client settings and history remain in their data home.
