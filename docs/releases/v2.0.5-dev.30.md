This candidate was not published. Publication was cancelled after AddressSanitizer found a late progress-callback lifetime defect. The corrected successor is [dev.31](v2.0.5-dev.31.md).

This preview shows each stage of local-kit updates in Monitor and the terminal.

- Monitor opens its EN/RU Sand progress window before rechecking the reviewed release. A full twelve-step list marks observed completed work and highlights the current step and its elapsed time.
- Downloads and staging show actual byte counts and percentages. Project compatibility and readiness checks show completed/total project counts. Service shutdown, kit replacement, startup, final confirmation and rollback have separate statuses. Work without a measurable total remains indeterminate.
- Terminal updates display readable progress on stderr automatically when attached to a terminal. Add `--progress` to include it in redirected logs. The final JSON receipt remains separate on stdout, and the language follows LC_ALL/LC_MESSAGES/LANG.
- Child progress is observed independently from the native update receipt. A missing or broken progress channel does not certify, retry or terminate installation. Only the installed-kit readback confirms completion; existing preservation and recovery checks remain in force.

Local verification passed 15 focused checks, including native EN/RU progress renders, real terminal PTY/heartbeat and closed-channel checks, child-transport refusal handling, and disposable installation/update/interruption/rollback with history preservation. The matching Linux/macOS CI matrix and exact macOS archive must also pass before publication. See [#24](https://github.com/toseek-samurai/shin-context-engine/issues/24).

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core remains 2.0.5-dev.3; Observer/CLI/MCP are 2.0.5-dev.30 and Monitor is build 54. Native Windows execution is not part of this preview's qualification.
