This preview fixes compound document retrieval that could block project refresh validation.

- A full budget of strict row matches no longer hides a declared JSON or Markdown document whose query terms span several sections. Compound multi-owner queries admit complete document units through the existing bounded planner. Exact owner and identifier routes, independent-record isolation, lifecycle/provenance checks and output budgets remain in force.
- Large Pack failures retain their case ID, reason codes and primary verification path through both failure-header and aggregate-validation reductions. Monitor and MCP receive the safe bounded diagnostic instead of an empty case list; omitted details remain explicitly marked.
- The native updater supports explicit format-preserving transitions from Core dev.1/dev.2/dev.3 to dev.4. Every project still requires readiness qualification, and failed or interrupted activation retains the existing rollback and authority-preservation checks.

Local verification covers the synthetic saturated-budget retrieval regression, independent-record negative controls, both diagnostic truncation layers, and disposable native update/migration and rollback. The matching Linux/macOS CI matrix and exact macOS archive must pass before publication. See [#25](https://github.com/toseek-samurai/shin-context-engine/issues/25).
