- Recovery processes one raw document group at a time and excludes independent source facts from whole-document corroboration. Existing candidate, output and prefix-completion limits, provenance boundaries and project validation gates remain enforced. A genuinely oversized final set reports the budget-exceeded reason separately from incomplete postings.

Python behavior and the generated secret-redaction test value are unchanged. Secret detection remains enabled.
