This preview brings the Sand terminal interface to `shin-ce stats` and preserves verified read access when a previously qualified project reaches its configured source limits.

- The macOS/Linux terminal monitor uses statically linked FTXUI 7.0.3, with Overview, Projects, Timing, Storage and Models views. Line charts retain missing observations and service-run boundaries. Keyboard and mouse navigation, compact layouts, live EN/RU switching, monochrome and basic-terminal fallbacks are included. No curses, Python or JavaScript runtime is needed for the TUI.
- A file-count or per-file size limit no longer makes every read unavailable on a previously qualified canonical route. Shin retains its approved snapshot and returns only unchanged, verified files, explicitly reporting partial coverage and `canonical_ready=false`. New, changed, deleted or unverified files remain withheld. Limits, profiles, publisher ownership and validation requirements stay in force; incomplete candidates are not published.
- Background observation restores full qualification when the inventory fits again. Stable partial observations use bounded idle scheduling, and service/Monitor/TUI diagnostics explain the limitation and expose its counts. Candidate qualification also handles the older controller's persisted refusal without rewriting project state.
- The README includes native TUI views, with a nine-screen gallery and reproducible captures. Installation, Linux/WSL build instructions, dependency notices and agent guidance have been reviewed; the current v22 generator and readable v21 baseline are distinguished explicitly.
- Client-settings test fixtures now use private permissions independently of the host umask. A separate regression retains refusal for group-writable settings directories; product permissions are unchanged.

Local verification covers native TUI rendering and real PTY interaction, EN/RU diagnostics, project/service lifecycle, source-limit recovery and preservation, plus strict self-profile validation. The Sand TUI was separately exercised with the complete Linux Observer suite on Ubuntu 24.04 WSL2 with GCC 13. The exact combined source tag, Linux/macOS CI matrix and macOS archive qualification must pass before this preview is published. Synthetic gallery values are examples, not performance measurements.

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core is 2.0.5-dev.5; Observer/CLI/MCP are 2.0.5-dev.38 and Monitor is build 62. Linux terminal tools are available through source builds; a Linux desktop package and native Windows qualification are not included.

In Monitor, choose **Check for updates** and confirm that the offered version is **2.0.5-dev.38**. After updating, restart or reconnect persistent MCP clients. Project authority, settings and history remain in the existing data home. Partial availability preserves access to verifiable existing files; it does not expand the approved project scope or make an over-limit inventory fully current.

For manual installation, use `install.sh` attached to this release.
