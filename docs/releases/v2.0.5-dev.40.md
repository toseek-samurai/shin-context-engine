This preview fixes update admission for projects with verified partial source coverage and recovery of a previously degraded runtime.

- The first background check preserves its admitted partial result. A concurrent installer check no longer mistakes that short startup window for a completely unavailable project.
- Cold admission handles an older controller that rejected source limits before saving an observation. It verifies the configured limit, unchanged approved profile and exact publisher head, and returns only independently verified selected files. New or changed files remain withheld; limits, grants and full publication requirements are preserved.
- Every running-kit update records the previous project-readiness baseline, including Observer-only updates. A confirmed pre-existing source-limit refusal no longer prevents restoration of the previous runtime after failed activation. Recovery still reports degraded projects; it does not mark them ready.
- An explicit `update --accept-degraded-rollback` recovery option handles legacy same-Core journals that lack this baseline. It only completes restoration of the previous payload and never begins a new update. Unknown, identity, integrity, registry and format failures remain blocking. See [legacy recovery](https://github.com/toseek-samurai/shin-context-engine/blob/v2.0.5-dev.40/docs/local-kit.md) before using it.

Local verification includes a deterministic first-check regression and an isolated installation of the real dev.36 kit: source-limit refusal, failed activation, rollback, legacy review, hard-format refusal and successful subsequent update. Profiles, bindings, grants, canonical publication, registry, identity and history storage are preserved. The matching Linux/macOS CI matrix and exact macOS archive qualification must pass before publication.

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core is 2.0.5-dev.5; Observer/CLI/MCP are 2.0.5-dev.40 and Monitor is build 64. The Sand TUI from dev.39 remains included. Linux terminal tools are available through source builds.

For an ordinary update, choose **Check for updates** in Monitor and confirm **2.0.5-dev.40**. A retained recovery journal must be reconciled first; the new recovery option intentionally leaves the previous version installed. After updating, restart or reconnect persistent MCP clients.

For manual installation, use `install.sh` attached to this release.
