This preview lets permanent profiles live with their projects and updates inherited source budgets.

- `shin-ce profile-relocate --profile-dir DIR` switches an enrolled, managed project to an exact copy of its approved profile. It requires a stopped service and preserves publisher permission, project identities, approval and profile history, and the existing index. A private journal resumes interrupted writes; unknown changes are refused. Completed moves can be reversed while the previous profile copy remains available.
- Keep project-specific profiles outside their selected document and source roots, for example in the project's `profiles/` directory. Verify service readiness after relocation before deleting the previous copy. See [profile relocation](https://github.com/toseek-samurai/shin-context-engine/blob/v2.0.5-dev.42/docs/local-kit.md#moving-an-existing-permanent-profile).
- Core defaults to 10,000 source files and 1 MiB per file when a profile omits these fields. Explicit reviewed overrides remain authoritative; the new-project generic template still declares 15,000 files and 1 MiB. These extraction budgets do not guarantee peak memory or determine how much text an agent receives.
- Source observation detects changed profile provenance and changed effective budgets even when raw profile hashes and selected file inventories are unchanged. The ordinary managed publisher validates and publishes a matching generation.
- The updater admits explicit forward Core transitions from dev.1 through dev.5 to dev.6. Generator-v22 storage and evidence formats are preserved. Per-project qualification, ownership, refusal of unknown transitions and rollback checks remain in force.

Local macOS verification passed nine focused suites and all six exact-archive stages, covering profile relocation, reverse relocation, interrupted writes, conflicting metadata, source observation, policy inspection, service admission, installation/update/recovery, EN/RU GUI and terminal restoration. The matching Linux/macOS matrix and exact CI archive checks must pass before this preview is published. Consumer installations and their private profiles are not changed by publication.

macOS 15 or newer, Apple Silicon. Ad-hoc signed preview; Developer ID signing and notarization are not included. Core is 2.0.5-dev.6; Observer/CLI/MCP are 2.0.5-dev.42 and Monitor is build 66. Linux terminal tools remain available through source builds.

Update through **Check for updates** in Monitor and confirm **2.0.5-dev.42**. After updating, restart or reconnect persistent MCP clients. Profile relocation is an explicit maintenance operation; installing this preview does not automatically change custom profile locations.

For manual installation, use `install.sh` attached to this release.
