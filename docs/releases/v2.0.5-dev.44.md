# v2.0.5-dev.44

This candidate was not published: CI exposed an incorrect all-requests-must-run
assumption in the bounded queue test. See dev.45 for the corrected qualification.

This preview improves offline retrieval, makes short periods of project preparation
transparent to MCP callers, and adds clearer local evidence about context use.
It includes Core 2.0.5-dev.7.

- Core document search uses Unicode NFC and full case folding, including Cyrillic
  and canonically equivalent text. Prefix limits count characters. The current
  index format is `shin-generator-v23-unicode-lexical`; older indexes are rebuilt
  from approved sources, with no old retrieval reader or dictionary conversion.
- Native source search removes common EN/RU question words, normalizes English
  inflections, and adds bounded English hints for Russian software terms. Broad
  descriptions prioritize different files before second fragments, within the
  existing result budget. This is lexical search, not general translation or a
  guarantee that an open-ended question will locate its implementation.
- `shin_status` reports a preparing reader as a pending status without claiming
  readiness or returning a snapshot. `shin_query` waits automatically for up to
  20 seconds for readiness in one cancellable call. Clients that send a progress
  token receive elapsed-time notifications. Warm queries do not incur a delay;
  permission, policy and integrity failures still return explicit refusals.
- MCP invocation history distinguishes adapter calls, service execution and
  delivery. Optional real session/model labels remain caller-reported; unknown
  attribution is retained. Local episode and repeated-read analysis helps inspect
  context use without call quotas or claims of model success/token savings.
- Explicit `shin_checkpoint` and `shin_resume` tools keep compact task notes and
  assess them against current code. Notes are caller assertions and never replace
  source verification or grant authority.
- Monitor and terminal statistics expose session/context activity and clearer
  admission diagnostics. Status/help remain available while bounded source calls
  are occupied.
- The updater rebuilds owned indexes across the format transition, preserves
  project settings, grants and history, and can restore the previous kit after
  failed activation. A bootstrap publication unreadable by the restored CLI is
  retired through the owned temporary-publication lifecycle before rebuilding.
  Interrupted operations remain recorded for a repeat of the same update command.

Restart persistent MCP connections after installing the preview so their adapters
match the service. Existing client settings and project registrations stay in
place. Desktop builds remain unsigned previews without Developer ID notarization.

The dev.43 candidate was not published. This release batches native FIFO test
traffic before admission, isolates its subsecond assertions, and separates the
real 60-second refresh deadline test from the general service suite. Every
service case and all product deadlines, queue bounds and ordering assertions
are retained; per-case durations are printed in CI.
