# v2.0.5-dev.50

This preview fixes Monitor's update handoff and gives its review window a compact
Sand layout. It retains the TUI charts and independent Updater introduced in
dev.49, Core 2.0.5-dev.7 and the Unicode v23 index format.

- Monitor reads CLI replies and diagnostics on separate bounded channels. The
  bootstrap's download message can no longer hide the helper's acknowledgement
  and prevent Monitor from closing. The acknowledgement must come from stdout
  with the actual child PID, including when it arrives in fragments.
- The GUI bootstrap leaves terminal progress to terminal clients. If Monitor
  cannot close, the helper preserves the current kit and returns the saved cause;
  Monitor retains its reader until the handoff actually completes. The existing
  shutdown deadline and response-size bound are unchanged.
- The review window fits its content, displays installed and offered versions,
  gives installation the Sand accent, and keeps release notes and diagnostics
  accessible. Errors and their next action stay visible in live and saved
  results. EN/RU switching preserves the current review and translates its cause.
- Native process regression checks exercise bootstrap chatter, fragmented
  acknowledgements, real Cocoa termination, refused termination, incorrect PIDs,
  stderr-only acknowledgements and bounded output without touching an installed
  service.

If an existing Monitor cannot start the update, quit Monitor and run this
release's versioned installer. It downloads the verified independent Updater;
project settings and history stay in their recorded home. Reopen Monitor and
reconnect persistent MCP clients after installation. Desktop builds remain
unsigned previews without Developer ID notarization.
