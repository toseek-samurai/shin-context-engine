# v2.0.5-dev.51

This candidate was not published. macOS ARM64 runners were unavailable and the
superseding [dev.52](v2.0.5-dev.52.md) adds a retrieval correction to this UI work.

This preview gives Monitor's Sessions tab a readable Sand activity journal.
Core remains 2.0.5-dev.7 with the Unicode v23 index format.

- Recorded MCP calls and explicit client events appear newest first, with UTC
  timestamps, short opaque session IDs, a monospace font,
  vector icons and distinct success, error, unfinished and host-event colors.
  The text identifies each outcome independently of its color.
- Session call/error counters, expandable details and recording notes replace
  the continuous diagnostic text. Empty and unavailable data have separate
  explanations. English and Russian labels update with the selected language.
- The journal shows at most eight recent sessions and six events per session,
  including host markers: 48 events in total. The visible count and ceiling are
  shown in the tab. Wrapped rows scroll within the content area; they cannot
  cover the fixed footer. The view does not accumulate events between responses.
- Display limits preserve stored observations, analysis totals and existing
  retention rules. Native EN/RU checks exercise a full 48-event journal, narrow
  layouts, scrolling to its final controls and the unavailable/empty states.

Update through Monitor's **Check for updates…** action. The independent Updater
shows progress while replacing the kit; project settings and history stay in
their recorded home. Reconnect persistent MCP clients after installation.
Desktop builds remain unsigned previews without Developer ID notarization.
