# v2.0.5-dev.52

This preview combines the Sand Sessions journal with Core 2.0.5-dev.8, which fixes
an explanatory-query failure that could block project refresh validation.
The Unicode v23 index format is unchanged.

- In questions such as `how engines work with SQL`, the conversational verb no
  longer becomes a required document word. Russian `как работает …` questions
  receive the same treatment. Focused references remain discoverable even when
  other documents happen to contain the generic verb.
- Literal `work` searches, `work queue`, quoted/call syntax and qualified code
  identifiers retain their terms. Regression checks cover explanatory retrieval
  in both languages and disk/resident parity. Project validation requirements,
  source limits and mandatory expected paths remain unchanged.
- Monitor's Sessions tab shows recent MCP calls and explicit client events in a
  readable monospace Sand journal with UTC timestamps, opaque session IDs,
  vector icons and distinct outcome colors. Counters, details and interpretation
  notes remain separately accessible in EN/RU.
- The desktop view shows at most eight sessions and six recent events per
  session, including host markers: 48 events in total, with a visible count and
  ceiling. Wrapped rows scroll inside the content area. Stored calls, analysis
  totals and existing retention rules are preserved.
- The README and CLI guide describe the journal and include native EN/RU
  screenshots rendered with independent synthetic data.

Update through Monitor's **Check for updates…** action. The independent Updater
shows progress while replacing the kit; project settings and history stay in
their recorded home. Reconnect persistent MCP clients after installation.
Desktop builds remain unsigned previews without Developer ID notarization.
