# v2.0.5-dev.54

This preview integrates the native Windows development route into the shared
Shin source tree and hardens its installer versioning. The published binary kit
continues to target macOS 15+ on Apple Silicon; Windows distribution remains
subject to its own installed-lifecycle and release-pipeline qualification.

- Windows x64 builds use the same Core, Observer, MCP contracts and shared
  Monitor presentation. Dedicated CMake presets and Windows CI cover native
  source checks; Linux/macOS qualification remains independently required.
- Windows history handling retries transient rollback-journal deletion while
  preserving private ACL checks and committed data. Shared refresh regressions
  and EN/RU documentation-warning checks also run on Windows.
- MSI versions distinguish development previews, release candidates and stable
  versions. Product identities are reproducible; same-version replacement is
  disabled, and compiled-package checks verify upgrade and downgrade bounds.
- A separate Windows kit preset and documented ZIP/MSI checks keep packaging
  distinct from source testing. The README footer links platform badges to the
  appropriate binary-installation or source-build instructions.

Core remains 2.0.5-dev.8. Windows TUI, automatic client connection, usage
collection and in-app updating are still pending. See
[Windows source status](../windows-desktop.md) for current scope.

Existing macOS installations can update through Monitor. Projects, settings and
history remain in their recorded home; reconnect persistent MCP clients after
updating. The macOS kit remains an ad-hoc-signed preview without Developer ID
notarization.
