# v2.0.5-dev.55

This preview improves access to macOS Monitor and introduces guarded Windows
x64 ZIP/MSI downloads alongside the macOS kit.

- Monitor's menu-bar icon keeps a fixed width when an update is available. Its
  update indicator stays inside the icon, preserving its accessibility label.
- Opening Monitor uses a standalone window when the menu-bar item cannot
  anchor its popover. Window ownership, focus, reopening and Compact view are
  covered by native EN/RU checks.
- Monitor records launch and normal termination reasons to help investigate
  unexpected exits. This does not add automatic process restart.
- Windows packages join the Linux/macOS source qualification workflow. The
  publisher verifies the exact ZIP/MSI inventory, checksums, matching payloads,
  component versions and source/run identity before making downloads public.
- Windows package checks exercise rendering and init/query/stop as a standard
  user with a private temporary directory. Hosted checks explicitly use headless
  rendering; interactive notification-area and installed-lifecycle checks remain
  separate. Packaging reuses the tested build tree to avoid compiling it twice.

Core remains 2.0.5-dev.8. The Windows preview targets x64 on local NTFS. Windows
TUI, automatic client connection, usage collection and in-app updating remain
pending; see [Windows support](../windows-desktop.md) for scope and verification
boundaries.

Existing macOS installations can update through Monitor. Projects, settings and
history stay in their recorded home; reconnect persistent MCP clients after
updating. The macOS kit requires macOS 15+ on Apple Silicon and remains an
ad-hoc-signed preview without Developer ID notarization.
