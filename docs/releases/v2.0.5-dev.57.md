# v2.0.5-dev.57

This preview keeps verified project context available when declared search-quality
checks miss expected evidence, and fixes update checks on larger GitHub release feeds.

- Ordinary eval/Pack quality failures produce a bounded search warning while a
  safe, current index continues to publish and serve MCP queries, reads and
  inspection. Monitor, TUI and CLI expose the warning. It survives reader restarts
  and clears when a new generation passes its checks.
- Strict Core `eval`, `validate` and `ready` verdicts and exit codes remain strict
  for CI. Authority, freshness, integrity, invalid configuration, runtime errors,
  forbidden results and mandatory resource/output limits still block admission.
  Classification examines every case and variant before diagnostic truncation.
- Installation accepts current projects with search-quality warnings. The Core
  version advances to 2.0.5-dev.9 so the normal updater can requalify old managed
  indexes with the corrected admission policy. Existing project grants, profiles
  and evaluation expectations are preserved.
- The launcher and independent Updater now parse release metadata under the same
  1 MiB bound used by their HTTP transport. Local state retains its separate
  256 KiB limit; duplicate keys, excessive nesting and invalid assets are refused.
  This fixes `json-too-large` when the release list grows past 256 KiB.

## Updating an affected macOS installation

An installed launcher that already reports `json-too-large` cannot discover this
fix through Monitor. Download this release's `install.sh` from the release assets
and run it with `sh`; the versioned installer downloads and verifies the new kit
and delegates installation to its fresh Updater. The normal owned-installation
and recovery checks still apply. Projects, settings and history stay in their
recorded home. Reconnect persistent MCP clients after updating.

This release changes availability decisions, not search ranking. A warning remains
visible when a search-quality check still fails.

The macOS kit requires macOS 15+ on Apple Silicon and remains an ad-hoc-signed
preview without Developer ID notarization. Windows x64 ZIP/MSI downloads retain
the boundaries in [Windows support](../windows-desktop.md); Windows in-app updating
remains pending. Public assets are published only after the guarded CI matrix and
exact package qualification succeed.
