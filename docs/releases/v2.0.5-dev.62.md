# v2.0.5-dev.62

Preview candidate. Publication is performed by the guarded CI publisher only after the matching source matrix and exact archive checks pass.

- Monitor stays in tray mode with a single popover-owned dashboard. Remove the standalone dashboard and automatic Dock fallback.
- Start and stop rendering with the popover lifecycle; native tests require sustained automatic Metal frames across reopening, focus changes, compact sizing and update review, without manually drawing frames.
- Accept mouse-moved events in the popup for ImGui pointer input.
- Installed Monitor uses macOS Login Items for launch at login, with an actual-status menu toggle, preserved external opt-out, approval handling and owned-registration removal during uninstall. Portable and development builds do not register.
- Multi-document prose matches with fewer than half the query groups in primary fields no longer suppress near-complete primary document evidence. Query coverage stays explicit and candidate, record, per-document and byte limits remain enforced.
- Broad multi-term searches no longer become restricted to one document just because the first topic word matches its filename stem. Explicit filenames, paths and compound component identifiers keep their owner scope.

Core: `2.0.5-dev.11`. Observer, Monitor and MCP: `2.0.5-dev.62`.
