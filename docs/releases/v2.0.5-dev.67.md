# v2.0.5-dev.67

Preview candidate. Publication is performed by the guarded CI publisher only after the matching source matrix and exact archive checks pass.

- Add bounded Objective-C and Objective-C++ syntax observations for `.m` and `.mm`: interfaces, implementations, protocols, categories, extensions, properties, complete method selectors and mixed C++ declarations. Preserve method headers, physical source ranges and distinct declaration/implementation identities. Message sends remain expressions, not definitions.
- Recognize Cocoa headers and method implementation fragments while preserving the established parser for valid C++ headers. Indexing needs no Cocoa SDK or Objective-C compiler; the pinned MIT grammar is built as vendored C11 with its notices included in portable installations.
- Include Objective-C-family files in automatic project discovery and the generic bootstrap profiles. Extend the UI, Observer and Observer-test profiles to cover their native Mac sources without increasing file or byte budgets. Add search checks for the Mac lifecycle, project setup and update window.
- Verify exact method-body reads, CRLF and fragment coordinates, cold/resident reader parity, same-line method identities, malformed input and existing parser limits.

## Index rebuild

The current generator is `shin-generator-v24-objective-cpp`. Older snapshots require rebuilding from approved project sources; there is no compatibility reader or conversion of old index data. Managed projects use their normal publisher to prepare and qualify the new snapshot. Standalone Core users run `build` explicitly. This does not authorize profile changes, re-enrollment or changes to project grants.

## Syntax boundaries

Arbitrary `.inc` fragments remain outside this syntax scope. The Objective-C++ grammar does not cover structured bindings or lambda init-captures; unsupported or malformed syntax remains visible as `syntax-incomplete`. These observations do not perform preprocessing, SDK lookup, type checking or call resolution.

Core: `2.0.5-dev.12`. Observer, Monitor, MCP and Updater: `2.0.5-dev.67`.
