# v2.0.5-dev.68

Preview candidate. Publication is performed by the guarded CI publisher only after the matching source matrix and exact archive checks pass.

- Fix `refresh-engine-changed` when updating a generator-v23 installation to the Objective-C++ release. Installer admission and project rebuilds share one explicit policy for known retired generators. Retrieval still requires the current generator; indexes are rebuilt from approved source.
- Qualify the bundled bootstrap profile's Objective-C extension update as part of the owned kit transaction. The installed profile must match its approved hash, all other policy fields must remain identical, existing file types must remain included, and only `.m`/`.mm` may be added. Record both profile revisions in the update journal and restore the previous revision on rollback. Other profile-policy changes require review and are refused before replacement.
- Preserve structured Core error codes in activation diagnostics instead of hiding them as `installation-update-failed`.
- Add generator-v23 first-read rebuild coverage, unknown/future generator refusals, and a cutover check requiring the immediately preceding generator to be represented in both rebuild policy and package qualification.
- Qualify each exact macOS archive against a checksum-pinned published generator-v23 kit: forward update, interrupted rollback with continuation, and refusal of an unqualified profile limit change. Check canonical and bootstrap routes, bindings, grants, source bytes and retained SQLite history.
