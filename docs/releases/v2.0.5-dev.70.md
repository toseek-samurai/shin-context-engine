# v2.0.5-dev.70

Preview candidate. Publication is performed by the guarded CI publisher after the matching source matrix and exact archive checks pass.

- Support a complete source-built Homebrew package with Core, Observer, CLI/TUI, MCP, usage collector and Monitor. Homebrew owns payload upgrades and login-service registration; native installation, self-update and native service registration are refused in this build.
- Generate stable opt-prefix MCP paths and retain only the known bundled profile alias in private project bindings. Resolve the physical registry for safe Observer IO, preserve profile hashes and canonical source/state checks, and refuse stale package generations or redirected registries.
- Give Homebrew Monitor a stable, generation-verified CLI locator and an EN/RU upgrade command dialog. Disable native update polling and keep native-kit login registration separate from Homebrew service management.
- Add package locator regression coverage and document installation, startup, upgrade, removal and existing-kit ownership boundaries.
- Include the merged Windows Monitor update controls: check complete Windows releases, open MSI/checksum links and release notes, and remove conflicting ImGui control IDs.

Core: `2.0.5-dev.13` (generator v24). Observer, Monitor, MCP: `2.0.5-dev.70`.
