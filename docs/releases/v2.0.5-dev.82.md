# v2.0.5-dev.82

Preview candidate. Each platform becomes available only after its own source
and exact-archive CI qualification passes. Pending macOS ARM runners do not
block qualified Linux or Windows downloads.

- Keep the root agent instructions within their existing 4000-byte budget,
  preserving all independent-publication and source-safety rules.
- Preserve a healthy resident reader when an empty or whitespace query is
  rejected. The next valid query keeps its qualified snapshot and warm reader;
  source-change and snapshot protections remain mandatory.
- Publish platforms independently, with serialized asset additions, immutable
  checksums and per-platform receipts tied to the exact CI source/run/attempt.
  Recheck authority before each mutation and confirm release notes by readback.
  Existing platform downloads are verified rather than replaced when another
  platform finishes later.
- Add the Ubuntu 24.04 x86_64 terminal archive: Core, Observer, CLI, MCP, usage
  collection and EN/RU TUI. It needs glibc 2.39+, libstdc++6, OpenSSL 3 and SQLite
  system packages. It includes no Linux desktop host or automatic updater.
- Qualify Linux archive inventory, hashes, ELF/system dependencies, relocated
  CLI/MCP snapshot reads and terminal restoration with synthetic projects.
- Keep the existing subsecond FIFO collision assertion in the serial FIFO
  test group, preserving its production deadline and all assertions.

Core remains `2.0.5-dev.15`; Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.82`. Generator remains `shin-generator-v24-objective-cpp`.
No profile scope or resource limit is increased by this preview.

Compact MCP document delivery still uses four records, at most two per document.
It can omit an owner found by an eight-record profile evaluation; this release
does not claim to resolve that separate retrieval-budget limitation.

Download pins remain on the previously published preview until new platform
assets are public. Local stress and package checks do not replace guarded CI
qualification of the exact release source and archives.
