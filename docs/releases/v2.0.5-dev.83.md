# v2.0.5-dev.83

Preview candidate. Each platform becomes available only after its own source
and exact-archive CI qualification passes. Pending macOS ARM runners do not
block qualified Linux or Windows downloads.

- Introduce Light Sand for macOS and Windows Monitor: light inset surfaces,
  warm framing, larger text, compact labeled buttons and distinct project states.
- Organize everyday tasks under Overview, Projects, History and Settings.
  History opens with the recorded-call journal; response times and optional
  agent usage remain available as secondary views. Technical reports are
  disclosed from project details.
- Keep version and update access visible in the fixed footer. Preserve line
  charts, missing observation intervals, immediate EN/RU switching and the
  macOS tray-popover lifecycle.
- Bring project setup, update review and independent updater windows into the
  same light style. Preserve reviewed installation authority and recovery flows;
  the Windows installer log keeps its scroll position as progress arrives.
- Preserve blocked/offline status when retained warnings exist, show enrollment
  errors, and distinguish mean search duration from retained median values.
- Update the documentation with nine native macOS and six native Windows
  screenshots using synthetic data. The terminal keeps its dark Sand appearance
  and Activity navigation.

Local UI checks cover EN/RU, compact layouts, scrolling and native Windows
100/150/200% DPI interactions. Source-profile checks cover all 47 eligible UI
files. These checks do not replace guarded CI qualification of the exact
release source and packages or establish an installed MSI update test.

Core remains `2.0.5-dev.15`; Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.83`. Generator remains `shin-generator-v24-objective-cpp`.
No project profile scope or service resource limit is increased by this preview.

Download pins and the documented published-preview identity remain unchanged
until qualified platform assets are public. Screenshots document the development
UI captured before the release version bump.
