# v2.0.5-dev.84

Preview candidate. Each platform becomes available only after its own source
and exact-archive CI qualification passes. Pending macOS ARM runners do not
block qualified Linux or Windows downloads.

This preview carries the Light Sand desktop redesign from dev.83 and fixes its
Windows ZIP qualification gate. The native renderer now covers seven panel
sizes and expanded update details, but the archive checker still expected the
old five-size totals. It now requires exactly 84 regular, 42 cold-reader,
28 documentation-warning and 108 update renders, retaining the three failed
launch checks and all existing shell, focus, relocation and runtime assertions.
Coverage mismatches include the render report in the failure output.

The shared macOS/Windows desktop redesign includes light inset surfaces, Sand
framing, larger text and compact labeled actions. Navigation is Overview,
Projects, History and Settings; version and updates remain visible in the fixed
footer. EN/RU, line graphs and the macOS tray-popover lifecycle are preserved.
The documentation includes nine native macOS and six native Windows screenshots
with synthetic data. The terminal keeps its dark Sand appearance.

Core remains `2.0.5-dev.15`; Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.84`. Generator remains `shin-generator-v24-objective-cpp`.
No project profile scope or service resource limit is increased by this preview.

Local checks do not replace guarded CI qualification of the exact release
source and archives. Download pins remain unchanged until qualified platform
assets are public. Existing dev.83 assets and its immutable tag are preserved.
