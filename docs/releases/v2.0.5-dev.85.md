# v2.0.5-dev.85

Preview candidate. Each platform becomes available only after its own source
and exact-archive CI qualification passes. Pending macOS ARM runners do not
block qualified Linux or Windows downloads.

This preview carries Light Sand and the Windows archive-qualification correction
from dev.83/dev.84, and corrects two macOS service test isolation issues:

- Run the cancelled-waiter replacement case in the existing serial FIFO group.
  It requires both requests to succeed inside the real 500 ms admission window,
  so unrelated parallel CPU work must not spend that window. Queue cancellation,
  active-request preservation, successful replacement and telemetry assertions
  remain mandatory; the production deadline is unchanged.
- Fence both resident readers and capture both preparations immediately before
  the ignored-artifact scenario. Project B previously used its initial token
  from before independent setup/root-metadata events. Preserve original snapshot
  identities, exact post-artifact preparation equality, request sequence checks,
  automatic source refresh and cross-project isolation assertions.

The service and native filesystem event handling are unchanged. Real directory
metadata and ambiguous/coalesced events remain conservatively observed.

Core remains `2.0.5-dev.15`; Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.85`. Generator remains `shin-generator-v24-objective-cpp`.
No project profile scope, service limit or test deadline is increased.

Local checks do not replace guarded CI qualification of the exact release
source and archives. Download pins remain unchanged until qualified platform
assets are public. Previously published tags and assets are preserved.
