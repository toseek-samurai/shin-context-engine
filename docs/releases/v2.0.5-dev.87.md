# v2.0.5-dev.87

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- The macOS Updater can recover a reviewed update after an interrupted download,
  missing temporary files, or interrupted installation. A verified download can
  be retried offline, and an unfinished installation is tied to its original
  candidate. Monitor and the terminal dashboard show the available recovery action.
- Kit updates report project preparation separately from installation. Projects
  that need background preparation can finish after the kit is replaced. Binding
  and approval checks still apply. A kit can update across Core revisions before
  its first project is enrolled. Windows reports pending preparation after MSI
  installation.
- On macOS, a persistent MCP session can resume after a compatible kit update
  once the adapter verifies the new runtime and its exact component versions.
  An older adapter needs one reconnect to gain this capability. An incompatible
  adapter or protocol requires reconnecting the integration.
- Local connection overload returns a structured busy response. The background
  qualification cache releases native watches under file descriptor pressure,
  and resource errors identify the exhausted resource.
- Cold readers reuse the verified snapshot description from their current
  qualification and check the copied bytes. The native service checks the
  search vocabulary budget before preparing a reader. Queries above the limit
  receive guidance to narrow the search.

Core is `2.0.5-dev.16`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.87`. The index generator is `shin-generator-v24-objective-cpp`.
