# v2.0.5-dev.88

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI. This preview includes the changes prepared for dev.87.

- The macOS Updater can recover reviewed updates after an interrupted download
  or installation. It can reuse a verified download offline. Monitor and the
  terminal dashboard show the available recovery action.
- Kit updates report installation and project preparation separately. Projects
  can finish background preparation after the kit is replaced. Binding and
  approval checks still apply.
- On macOS, persistent MCP sessions can resume after a compatible kit update.
  Older adapters need one reconnect to gain this capability. Changes to the
  adapter contract or protocol require reconnecting the integration.
- Runtime verification accepts Windows and Unix line endings in component
  version files while checking the exact bytes against their recorded hashes.
- Local overload returns a structured busy response. Qualification releases
  native watches under file descriptor pressure, and cold readers reuse the
  verified snapshot description. Queries above the vocabulary budget receive
  guidance to narrow the search.

Core is `2.0.5-dev.16`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.88`. The index generator is `shin-generator-v24-objective-cpp`.
