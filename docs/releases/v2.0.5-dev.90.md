# v2.0.5-dev.90

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- The macOS Monitor ships a 128-pixel logo to reduce the memory AppKit uses for
  its application icon.
- Background refresh retains verified checkpoints that fit when native watcher
  or metadata capacity is constrained. Changed sources and invalidated
  checkpoints still trigger full qualification.
- Refresh diagnostics report why a checkpoint was missed or could not be
  retained.

Core is `2.0.5-dev.16`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.90`. The index generator is `shin-generator-v24-objective-cpp`.
