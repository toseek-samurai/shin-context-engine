# v2.0.5-dev.92

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Core uses less peak memory during index generation by storing one posting list
  per term and releasing postings and fact rows as they are written. The index
  format and generator identity stay the same.
- Compact dictionary validation checks posting rows without allocating posting
  lists, reducing work during snapshot verification.

Core is `2.0.5-dev.17`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.92`. The index generator is `shin-generator-v24-objective-cpp`.
