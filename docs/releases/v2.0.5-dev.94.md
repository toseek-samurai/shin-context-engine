# v2.0.5-dev.94

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Project details show search counts, search errors and mean service response
  time, a line chart of recent search response times and the mix of recent
  search, inspect and read calls. The shared macOS and Windows screen supports
  EN/RU and the dark Sand theme.
- Analytics use the exact selected project identity. Retained history and recent
  requests from the current run have separate labels. Missing measurements,
  partial history and stale service responses are shown explicitly.
- The panel uses a single Sand outline. The bottom update button has space
  above and below it, including in compact layouts.
- Selecting a project returns its detail view to the top so its status is visible.

Core is `2.0.5-dev.17`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.94`. The index generator is `shin-generator-v24-objective-cpp`.
