# v2.0.5-dev.96

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Fix an update failure when no project has been connected yet: an absent
  project registry needs no bootstrap migration. Retry and recovery retain their
  installation checks without creating a project registry.
- New projects use a bootstrap profile with room for 30,000 source files and
  2 MiB per file. Search preparation follows the reviewed profile limits;
  files above the 1 MiB parser ceiling use bounded text chunks.
- Large generated artifacts can use the existing 256 MiB total snapshot budget
  without hitting a separate, smaller per-artifact limit. Capacity errors report
  the affected artifact and its budget; Monitor shows an actionable explanation
  in English or Russian.
- Retrying an unfinished first import can adopt the current bootstrap profile.
  Successfully prepared projects retain their approved profile revision.
- Cold search readers can finish preparing while background maintenance holds
  the workspace writer lock. Source freshness and authority checks still apply.
- Native updates migrate the qualified bundled bootstrap profile changes and
  retain the previous binding for rollback, including interrupted recovery.

Core is `2.0.5-dev.18`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.96`. The index generator is `shin-generator-v24-objective-cpp`.
