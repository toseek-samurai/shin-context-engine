# v2.0.5-dev.97

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Project connection reports real preparation stages: checking settings,
  building and checking the index, preparing search, starting the service and
  confirming readiness. The progress view supports English and Russian and
  shows elapsed time without an estimated percentage.
- macOS opens setup before connecting the folder and keeps it visible through
  completion. Failures remain in the same window with the error code and a
  retry path; successful connection proceeds to agent selection.
- Windows shows the same stages in its management page and preserves the
  connection result while discovering agents.
- Integrations can request `project-add --progress-json`: bounded stage frames
  use stderr while stdout remains the final JSON receipt. Native pipe readers
  handle fragmented frames and preserve errors on their original channel.
- Monitor uses a single Sand outline at the panel edge. The dark outer rim and
  the redundant outline around the project list are removed.

Core remains `2.0.5-dev.18`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.97`. The index generator is `shin-generator-v24-objective-cpp`.
