# v2.0.5-dev.99

Preview candidate. Each platform is published after its source and exact archive
pass qualification in CI.

- Use statically linked RE2 for the built-in secret scanner, with pinned source
  archives, fixed patterns and bounded compiled-pattern memory. Inspect credential
  values within local expressions instead of joining unrelated source lines.
  Environment and GitHub Actions references, typed function declarations and
  ordinary code identifiers no longer become credentials merely because their
  names contain `secret` or `token`.
- Preserve private-key, AWS, OpenAI, JWT, Bearer and credential-assignment checks,
  including multiline and unfinished source. Snapshot-bound source reads use the
  same scanner with source suppression disabled. This is the matching engine for
  Shin's built-in checks, not the complete Gitleaks ruleset or a guarantee that all
  secrets are detected. RE2 and Abseil require no separate runtime installation;
  their original license notices are included in the packages.
- Refresh the main README, platform and installation guidance, and 33 native
  Monitor and TUI screenshots in English and Russian. Clarify package ownership,
  project preparation, MCP reconnection and independent platform publication.

Core is `2.0.5-dev.19`. Observer, CLI, MCP, Monitor and Updater are
`2.0.5-dev.99`. The index generator remains `shin-generator-v24-objective-cpp`.
The Core change triggers normal engine qualification and managed source
regeneration after installation; project approval and freshness rules remain in
force.

Local qualification covers the complete macOS native source suite, 71 focused
secret-assignment cases, documentation checks and strict source profiles. Windows
screenshots come from the published dev.98 renderer and do not qualify the new
Core on Windows. The exact dev.99 archives and other platforms are qualified in CI
before publication. Existing installation links remain pinned to a fully published
preview until the new assets are available.
